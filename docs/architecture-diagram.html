Topologi Arsitektur Sistem Restoran "Mie Elon Musk"

Peta interaksi kanal pelanggan, kasir, dapur, dashboard admin, dan boundary Google OAuth.

DIAGRAM KONEKSI SISTEM & LAYER DATA REST-API · OAUTH2 · HMAC · MARIADB

Kanal Pelanggan (Customer Facing)

  • • Takeaway: Pemesanan bungkus online, checkout mandiri dengan estimasi waktu ambil.
  • • Dine-In (QR Meja): Penguncian meja otomatis via URL, validasi meja aktif/terisi.
  • • Order Tracking: Nomor tiket publik untuk memantau status masak secara transparan.

Otorisasi & Akun Staf (OAuth)

  • • Pendaftaran Terbuka: Staf mendaftar via akun Google asli tanpa password manual.
  • • Persetujuan Admin: Akun baru ditahan di status pending hingga disetujui di Admin.
  • • Penetapan Peran: Admin menentukan akses staf sebagai cashier, kitchen, atau admin.

Integrasi & Keamanan Data

  • • HMAC Signature: API internal Next.js dan Laravel dienkripsi dengan secret key.
  • • Statistik Riil: Omset admin hanya dihitung dari status paid di MariaDB.
  • • Stok Dinamis: Toggle ketersediaan menu di admin langsung memblokir pemesanan habis.
